## 🎮 About the Game

Skyline Sprint puts you on top of a futuristic city — 
running, leaping, and vaulting across rooftops in full VR.

The game was designed with a focus on **intuitive 3D user 
interface principles** and **natural VR movement**, making 
every jump feel physical and satisfying without causing 
motion sickness.

---

## ✨ Key Features

- 🏃 3+ custom player movement mechanics
- ⚙️ Dynamic locomotion and collision response
- 🏙️ Vertical city environment with rooftop traversal
- 🎯 Physics-based movement systems
- 🕹️ Intuitive VR hand controller interaction
- 🎓 Strong academic evaluation — JMU Würzburg 3DUI module

## 🚀 Getting Started

### Prerequisites
- Unity 2022.3 LTS or later
- Meta Quest Developer Hub
- XR Interaction Toolkit package
- Meta XR SDK

### Setup
1. Clone the repository
2. Open in Unity Hub
3. Install required packages via Package Manager
4. Connect Meta Quest via USB
5. Build and Run → Android → Meta Quest
