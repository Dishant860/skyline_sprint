# 🏃 Skyline Sprint — VR Parkour Game

> Immersive parkour-style VR game built in Unity (C#) for Meta Quest.
> Developed as part of the 3DUI (3D User Interfaces) module at
> Julius-Maximilians-Universität Würzburg.

## 🎬 Demo Video

[![Skyline Sprint Demo](h[ttps://img.youtube.com/vi/YOUR_VIDEO_ID/maxresdefault.jpg)](https://www.youtube.com/watch?v=YOUR_VIDEO_ID](https://youtu.be/Ilmp0nZGueo))

## 🎮 Features

- 3+ custom player movement mechanics
- Dynamic locomotion and collision response
- Physics-based level traversal in a vertical city environment
- Intuitive VR interaction design

## 🛠️ Built With

| Tool | Purpose |
|------|---------|
| Unity (C#) | Game engine |
| XR Interaction Toolkit | VR interactions |
| Meta Quest SDK | Standalone VR deployment |
